# Sistema de Controle de Portaria

## Sobre o projeto

Projeto desenvolvido para a disciplina de **Análise e Projeto de Sistemas**, com o objetivo de facilitar o controle de acesso de pessoas e veículos em uma portaria.

## Funcionalidades previstas

- Cadastro de moradores e funcionários;
- Cadastro de veículos;
- Cadastro e autorização de visitantes;
- Registro de entrada e saída de pessoas e veículos;
- Consulta ao histórico de acessos;
- Registro de ocorrências;
- Geração de relatórios de acesso.
