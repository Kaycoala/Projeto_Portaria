# Documentação do Projeto

Esta pasta reúne a documentação acadêmica do Sistema de Controle de Portaria.

| Arquivo | Conteúdo |
|---|---|
| `requisitos do sistema.docx` | Requisitos funcionais e não funcionais e regras de negócio. |
| `Casos_de_Uso_Sistema_Controle_de_Portaria.pdf` | Casos de uso textuais (UC01, UC02 e UC03). |
| [`Correspondencia_Modelagem.md`](Correspondencia_Modelagem.md) | Como cada classe do diagrama foi implementada no banco de dados. |
| [`prints/`](prints/README.md) | Capturas de tela reais do sistema e o roteiro para tirá-las. |
| `gerar_pdf.py` | Gera o PDF final (`Projeto_Portaria.pdf`) a partir dos diagramas, da documentação e dos prints. |

Os diagramas UML ficam na pasta [`diagramas/`](../diagramas/README.md).
