# Diagramas UML

Esta pasta contém os diagramas UML do Sistema de Controle de Portaria.

- **Diagrama de Casos de Uso:** apresenta os atores e as funcionalidades do sistema.
- **Diagrama de Classes:** apresenta as classes, seus atributos, métodos e relacionamentos.

Os arquivos PNG são destinados à visualização, enquanto os arquivos `.drawio` permitem editar os diagramas.
